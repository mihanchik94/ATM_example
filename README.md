## О проекте:
Тестовое задание по демонстрации возможности занесения или списания денежных средств со счета.

Приложение принимает по REST запрос вида:
```
 POST api/v1/wallet
{
valletId: UUID,
operationType: DEPOSIT or WITHDRAW,
amount: 1000
}
```
И после этого выполняет логику по изменению счета в базе данных.

Также приложением предусмотрена операция по получению баланса кошелька:
```
GET api/v1/wallets/{WALLET_UUID}
```
Неверные запросы возвращают пользователю сообщения об ошибке.

Приложение предполагает работу в конкурентной среде и должно выдерживать до 1000 RPS на 1 кошелек.

Как видно из результатов локального тестирования, приложение соответствует заявленным требованиям.
Данные результаты предварительные и требуют более тщательного тестирования, а также подробного мониторинга данных 
с использованием, например, Prometheus, чтобы при выявлении проблем можно было понять, где, и в каких сценариях 
могут возникнуть эти проблемы и что именно нужно оптимизировать.

Для интеграционного тестирования контроллеров был использован PostgreSQLContainer.
Это позволяет сымитировать рабочую среду и проверить, как база будет себя вести при выполнении запросов.
Также данное решение позволяет гибко настраивать процесс тестирования и легко интегрируется в CI/CD.

На случай дальнейшего расширения приложения был создан базовый класс, от которого будут наследоваться все интеграционные тесты. 
Это не только улучшает читаемость отдельно взятых тестов, но и позволяет оптимизировать процесс тестирования, 
поскольку при таком подходе Spring будет поднимать 1 контекст для всех интеграционных тестов.

Сборка приложения осуществляется через Docker-compose.
Dockerfile разбит на 2 этапа: сборку и развертывание, что позволяет собрать более легковесный образ.

### Установка
#### Ручная настройка

1. Установите и настройте PostgresSql:

* Загрузите и установите PostgresSql 14 с [официального сайта](https://www.postgresql.org/download/).
* Запустите сервер PostgresSql.
* Создайте базу данных с именем wallet-db или измените имя базы данных в переменной среды DATABASE_URL.

2. Клонируйте репозиторий на локальный компьютер, выполнив следующую команду:

```
cd existing_repo
git remote add origin <URL>
git branch -M master
git push -uf origin master
```

3. Откройте IDE.

4. Откройте проект, выбрав «Открыть» и указав путь к каталогу проекта.

5. Поскольку в проект не добавлены параметры для переменных сред и по умолчанию БД настроена на работу с Docker,
перейдите в файл application.yaml и внесите там следующие изменения:

```
datasource:
    url: URL базы данных. (Пример: "jdbc:postgresql://localhost:5432/wallet-db")
    username: Имя пользователя базы данных.
    password: Пароль базы данных.
```

6. Запустите проект.

### Настройка Docker
Убедитесь, что у вас установлены [Maven](https://maven.apache.org/) и [Docker Compose](https://docs.docker.com/compose/).

В терминале перейдите в корневой каталог проекта.
Выполните следующую команду для сборки проекта и создания образа Docker:

```
mvn clean install
docker-compose up
```

После выполнения этих шагов ваш проект должен быть успешно установлен и запущен.

### Взаимодействие
